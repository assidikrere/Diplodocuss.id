# Diplodocuss Website Prototype

A static, mobile-first brand website prototype based on the current Diplodocuss brand foundation.

## Pages
- `index.html` — Home
- `tentang.html` — Tentang Diplodocuss
- `menu.html` — Menu
- `persinggahan.html` — Persinggahan
- `cerita.html` — Cerita

## Design direction
- Base: soft white + soft black
- Warmth: photography + product colors, not a brown/beige site background
- Typeface CSS stack: General Sans first, then system sans fallbacks
- Handwritten accent: Caveat first, system cursive fallback
- Photography: people & moments first
- Principle: real life, well framed

## Links to replace before publishing
- The current order CTA uses `https://bit.ly/kopsus_diplodocuss` as the known brand short link.
- WhatsApp buttons are placeholder `#` links and should be replaced with the intended WhatsApp destination.

## Local preview
Open `index.html` directly in a browser, or run a local server:

`python3 -m http.server 8080`

then open `http://localhost:8080/`.

## Font note
The prototype does not bundle font files. For production, use a properly licensed/hosted copy of General Sans and Caveat.
